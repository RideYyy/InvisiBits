How LSB embedding works
Every color channel is a number from 0 to 255. InvisiBits replaces only its least significant bit, so a used channel changes by at most one. The alpha channel and partially transparent pixels are left untouched. WAV encoding follows the same idea using PCM samples.
10110110 → 10110111The value changes from 182 to 183.

            
Password protection
The password is not used as a key directly. PBKDF2-HMAC-SHA-256 combines it with a fresh 16-byte salt and performs 250,000 iterations. The resulting 256-bit key encrypts the message with AES-256-GCM and a random 12-byte IV.
AES-GCM also authenticates the encrypted data. A wrong password or a modified payload fails safely instead of displaying damaged text. Salt and IV are stored in the container; the password is never stored.

            
Compression and integrity
Deflate compression is kept only when it makes the UTF-8 message smaller. The container records its version, flags, lengths, and a CRC32 checksum so regular images, incomplete payloads, and unsupported versions can be rejected clearly.
